LIMO PRO is a mobile robotics development platform developed by AgileX Robotics for robotics education, autonomous navigation research, AI development and rapid prototyping.

The platform supports four interchangeable mobility configurations: Ackermann steering, differential drive, Mecanum-wheel drive and tracked drive. These configurations enable developers to explore different mobile robot kinematics and navigation strategies using a single platform.

LIMO PRO integrates NVIDIA Jetson Orin Nano computing, an EAI T-mini Pro 2D LiDAR, an Orbbec DaBai depth camera and an HI226 IMU. Its onboard computing and perception hardware support mapping, localization, sensor fusion, computer vision and autonomous navigation development.

LIMO PRO supports ROS 1 and ROS 2, with C++ and Python development interfaces, open-source ROS packages and simulation resources. Supported mapping and navigation algorithms include Gmapping, Cartographer, RTAB-Map, AMCL, DWA and TEB.

The platform can be used for classroom experiments, autonomous navigation, obstacle avoidance, visual recognition and mobile robotics research.
